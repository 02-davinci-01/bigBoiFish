Drop your "song of the day" mp3 files here.

The player reads its track list from  src/data/songs.ts
Each entry's `src` should match a file in this folder, e.g.:

  public/audio/song-of-the-day.mp3   ->   src: "/audio/song-of-the-day.mp3"

The first entry in songs.ts is the current song of the day; add more below it
over time and the vinyl player's prev/next buttons will flip through them.
